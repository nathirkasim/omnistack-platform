# Examples

This directory contains different examples of using this project's layout for
applications in different frameworks.

Please remember the following as you browse through those examples:

1. Setup each of your applications in their own repositories on top of a clean
   setup of this template project. This should simplify matters a great deal,
   as you hereby achieve the flexibility of changing the project files (such as
   Dockerfiles and Makefiles) without having to worry about breaking the
   configuration for other applications in subdirectories of the template
   project. The example used for setting up multiple examples within the
   repository is just for demonstrative purposes.
